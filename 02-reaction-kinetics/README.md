# 02 — Reaction Kinetics

First-order batch kinetics and Arrhenius temperature dependence.

```
A -> P
CA(t) = CA0 exp(-kt)
X(t) = 1 - exp(-kt)
k(T) = A exp[-Ea/(R T)]
```

Run: `python kinetics.py`

The model assumes a constant-volume, well-mixed batch system with one irreversible first-order step. Complex systems may require reversible or parallel reactions, transport limitations, catalyst deactivation, or an energy balance.
